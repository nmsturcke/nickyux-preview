Sentry-To-GitHub

From an error alert to an issue your team can act on.

Repository being prepared for release
My roleCreator & developer
FocusSelf-hosted developer tooling

Keep errors with the code.

Sentry-To-GitHub is a self-hosted Python service that turns Sentry alerts into GitHub issues, helping developers track errors alongside their code.

The implementation.

Built with Quart and MongoDB, the service uses GitHub App authentication. Repositories, labels, and assignees are configurable to fit the team’s workflow.

Opening the source.
